# DigiPixel email signature image

Uses the **exact user-selected blue-background headshot**, resized only to 400px square, from `../assets/portrait/matt-digipixel-400.jpg`. The portrait is hosted in the same portfolio preview repository under the public `/assets/portrait` URL. Email markup uses a table with explicit dimensions for Outlook compatibility.

Preview: `/digipixel-email-signature/`.

**This is a prepared template, not an installed or sent signature.** As of 2026-10-29 the DigiPixel Graph Bridge mailbox reports `signatureConfigured=false`. Its configuration must be deliberately updated through the approved DigiPixel process; do not send prospecting emails before an authorised signature is confirmed.

Email: `matt@digipixel.uk`. Website: `https://digipixel.uk`.
